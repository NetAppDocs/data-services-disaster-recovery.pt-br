= Adicionar clusters locais e do Amazon EVS vCenter no NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Após criar os sites, adicione os clusters vCenter para cada site no NetApp Disaster Recovery. O tipo de site determina o acesso que o NetApp Disaster Recovery requer para os vCenters nesse site. Amazon Exchange Virtual Server vCenters e vCenters locais usam as mesmas informações de conexão e autenticação.

.Etapas para adicionar um vCenter a cada site
. Na opção *Sites*, selecione *Adicionar vCenter* para o site desejado.
+
image:evs-add-vcenter-1.png["Adicionar opção vCenter"]

. Na caixa de diálogo Adicionar servidor vCenter, selecione ou forneça as seguintes informações:
+
.. O agente do NetApp Console hospedado na sua VPC da AWS.
.. O endereço IP ou FQDN do vCenter a ser adicionado.
.. Se necessário, altere a porta para a porta TCP usada pelo seu servidor vCenter.
.. O nome de usuário do vCenter para a conta criada anteriormente que será usada pelo NetApp Disaster Recovery para gerenciar o vCenter.




. Se sua organização utiliza uma autoridade de certificação (CA) externa ou o vCenter Endpoint Certificate Store, desmarque a opção *Usar certificados autoassinados*. Caso contrário, deixe a caixa marcada.
+
.. Selecione *Adicionar*.
+
image:evs-add-vcenter-2-3.png["Caixa de diálogo Adicionar vCenter"]
