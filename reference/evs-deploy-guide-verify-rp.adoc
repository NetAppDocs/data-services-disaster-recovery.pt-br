= Verifique se tudo está funcionando no NetApp Disaster Recovery
:allow-uri-read: 


[role="lead"]
Após adicionar um plano de replicação no NetApp Disaster Recovery, verifique se o plano está no estado *Healthy* antes de continuar.

Figura: Página de planos de replicaçãoimage:evs-replication-plan-post-create.png["Página de planos de replicação"]

NetApp Disaster Recovery executa uma série de testes para verificar se todos os componentes, incluindo o cluster ONTAP, os clusters vCenter e as VMs, estão acessíveis e prontos para proteção. Isso é chamado de verificação de conformidade e é executado regularmente.

A página de planos de replicação exibe as seguintes informações:

* Status da última verificação de conformidade
* O estado de replicação do plano de replicação
* O nome do site protegido (fonte)
* A lista de grupos de recursos protegidos pelo plano de replicação
* O nome do site de failover (destino)
