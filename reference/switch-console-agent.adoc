= Alternar agentes do Console ao usar o NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
O NetApp Console suporta o uso de vários agentes do Console em um único ambiente de trabalho. Usar vários agentes do Console pode ser útil para manter o acesso aos recursos enquanto você realiza manutenção em outro agente do Console ou se um agente do Console falhar. Como cada agente do Console tem um identificador exclusivo, alternar agentes do Console de forma inadequada pode comprometer a disponibilidade de recursos em um ambiente de trabalho.



[[before-you-begin]]
== Antes de começar

* Você deve terxref:../get-started/dr-prerequisites.html#create-the-netapp-console-agent[Adicionou pelo menos dois agentes de console ao seu ambiente de trabalho.] .
* Ambos os agentes do Console devem conter os mesmos clusters ONTAP .




[[steps]]
== Passos

. Em Recuperação de Desastres, selecione **Sites**.
. Você precisa alterar o agente do console tanto para o vCenter de origem quanto para o de destino.  Identifique os vCenters que deseja modificar.  Selecione o menu de ações do vCenter e, em seguida, **Editar**.
+
image:dr-sites-subnet-menu.png["Captura de tela do painel de controle de Sites"]

. Selecione o agente do console que deseja usar no menu suspenso e insira novamente seu nome de usuário e senha do vCenter. Selecione **Salvar**.
+
image:edit-vcenter.png["Captura de tela da alteração do agente do console"]

. Repita os passos 2 e 3 para cada vCenter adicional que você deseja modificar.
. No vCenter que você modificou, atualize-o para que o novo agente do Console seja detectado.  Repita este passo para cada vCenter que você modificou.
. Em Recuperação de Desastres, navegue até **Planos de replicação**.
. Identifique os planos de replicação que deseja usar para retomar os fluxos de trabalho.  Selecione o menu de ações `...` Em seguida, **atualize os recursos**.  Você pode acompanhar o status das tarefas em **Monitoramento de tarefas**.
