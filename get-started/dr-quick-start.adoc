= Início rápido para NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
Aprenda como configurar o NetApp Disaster Recovery, garantindo que seu sistema atenda aos requisitos para descobrir cargas de trabalho com sucesso e configurar planos de replicação para se preparar para o failover.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]Revise os pré-requisitos
[role="quick-margin-para"]
A função de _Super admin_ ou _Organization admin_ é necessária para implantar um agente do Console e atribuir permissões.

[role="quick-margin-list"]
* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html["Implantar um agente de Console"^]
* link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Analise as funções de usuário do NetApp Disaster Recovery e atribua permissões aos usuários que precisam delas"^]
* link:../get-started/dr-prerequisites.html["Certifique-se de que seu sistema atenda a esses requisitos"]
* Certifique-se de atender aos requisitos adequados para o seu tipo de carga de trabalho:
+
** link:../get-started/reference-vmware-prerequisites.html["Pré-requisitos do VMware"]
** link:../get-started/task-kubernetes-requirements.html["Pré-requisitos do Kubernetes"]
