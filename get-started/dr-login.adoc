:allow-uri-read:

[role="lead"]
Para fazer login no NetApp Disaster Recovery, use suas credenciais do site de suporte da NetApp ou cadastre-se para um login em nuvem da NetApp com seu endereço de e-mail e senha. https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["Saiba mais sobre como fazer login"^].



[[user-roles]]
== Funções do usuário

Em NetApp Disaster Recovery, tarefas específicas exigem funções de usuário específicas. Certifique-se de que você atribuiu as funções corretas aos usuários.

Para obter mais informações, consulte: * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["Funções e permissões de usuário no NetApp Disaster Recovery"] * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["NetApp Console funções de acesso para todos os serviços"^]



[[log-into-disaster-recovery]]
== Faça login no NetApp Disaster Recovery

. Abra um navegador da web. Navegue até o  https://console.netapp.com/["NetApp Console"^].
. Efetue login no NetApp Console.
. Na navegação à esquerda do NetApp Console , selecione *Proteção* > *Recuperação de desastres*.
+
Se esta for a primeira vez que você faz login neste serviço, a página de destino aparecerá e você poderá se inscrever para um teste gratuito.

+
image:draas-landing6-free-trial.png["Captura de tela da landing page para NetApp Disaster Recovery"]

+
Caso contrário, o Painel de Recuperação de Desastres é exibido.

+
** Se você ainda não adicionou um agente do NetApp Console, adicione um. Para obter detalhes, consulte  https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["Saiba mais sobre os agentes do Console"^].
** Se você for um usuário do Console com um agente existente, ao selecionar *Recuperação de desastres*, uma mensagem sobre como se cadastrar aparecerá.
** Se você já estiver usando o serviço, ao selecionar "Recuperação de desastres", o Painel será exibido.
+
image:dr-dashboard.png["Painel de Recuperação de Desastres"]
